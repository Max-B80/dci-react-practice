# My Digital Space

A personal multi-page web application built with **React 19**, **TypeScript**, **TanStack Router**, **Tailwind CSS v4**, and **DaisyUI**.

## Features & Routes

- **Home (`/`)**: Welcome overview with quick navigation links.
- **Profile (`/profile`)**: Personal profile and course background.
- **Hobbies (`/hobbies`)**: Dynamic list of hobbies rendered from a typed array.
- **Tasks (`/tasks`)**: Interactive task manager supporting adding and deleting items using React state (`useState`).
- **Favorites (`/favorites`)**: Categorized list of favorite movies, music, and games.
- **Settings (`/settings`)**: Interactive toggles for theme preview and notification preferences.

## Tech Stack

- **React 19** & **TypeScript**
- **TanStack Router** (file-based routing with `__root.tsx` layout and `<Outlet />`)
- **Tailwind CSS v4** & **DaisyUI**
- **Vite**
